# 📊 Track A: Data Science & Analytics (Syllabus)

Welcome to the Data Science & Analytics specialization track. This module transitions students from standard core Python developers into data professionals who can process, clean, visualize, and extract business insights from millions of raw data rows [finance].

---

## 🗺️ Specialized Learning Roadmap

Click on any specific module sub-folder to access structured notes and source coding labs:

### 1. [Module 01: Advanced Vector Computations (NumPy)](./01-NumPy-Arrays/README.md) 🔢
*   Understanding Multi-dimensional Ndarrays.
*   Vectorization vs Element-wise traditional loops (Performance Benchmarking).
*   Matrix math, slicing configurations, and broadcasting dimensions.

### 2. [Module 02: Industrial Data Engineering & Wrangling (Pandas)](./02-Pandas-Data-Cleaning/README.md) 🐼
*   Data Manipulation using Series and DataFrames.
*   Importing large Excel sheets, CSV records, and flat raw data dumps.
*   **Data Cleaning Mechanics**: Handling missing NaN entries, dropping duplicates, filtering outliers, grouping aggregates, and table joins.

### 3. [Module 03: Graphical Data Journalism (Matplotlib & Seaborn)](./03-Data-Visualization/README.md) 📉
*   Designing production-quality visual plots.
*   Line charts, bar clusters, scatter plots, and density histograms.
*   Correlations heatmap plotting to find hidden business trends.

### 4. [Module 04: Relational Pipeline Integration (Python + SQL)](./04-SQL-Database-Integration/README.md) 🗄️
*   Connecting Python backend infrastructure to relational databases (SQLite / MySQL).
*   Executing structural queries (`SELECT`, `WHERE`, `GROUP BY`) inside Pandas using engine connections.
*   Exporting computed insights back into standard database warehouses.

### 5. [Module 05: Capstone Production Assignment](./05-Capstone-Data-Project/) 🚀
*   Hands-on cleaning and analysis of a real-world multi-thousand rows dataset.
